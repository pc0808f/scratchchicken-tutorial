# 🛡️ 第三週：母雞就位！放置第一座砲塔
{: .fs-9 }

這一週先讓老鼠開始沿著小路前進，再設計固定的砲位。玩家點擊空砲位，就能派出守衛母雞保護飼料桶。
{: .fs-6 .fw-300 }

[開始學習](#學習內容){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 }

---

## 🎯 本週學習目標

完成本週課程後，你將能夠：

- ✅ 從 Scratch 角色庫加入 `Mouse1`
- ✅ 使用滑行積木讓老鼠走過簡單路線
- ✅ 在背景上設計固定砲位
- ✅ 使用「角色被點擊」啟動程式
- ✅ 用條件判斷避免同一個砲位重複放置

## 🕒 本週 45 分鐘流程

| 時間 | 活動 | 完成標準 |
|---|---|---|
| 5 分鐘 | 開啟上週作品，確認背景和路線 | 找到老鼠洞與飼料桶位置 |
| 8 分鐘 | 加入 `Mouse1`，設定大小與起點 | 舞台上有一隻老鼠 |
| 7 分鐘 | 串接滑行積木，讓老鼠走到飼料桶 | 老鼠能走完一條簡單路線 |
| 8 分鐘 | 在背景畫出 3～4 個固定砲位 | 砲位不擋住老鼠小路 |
| 13 分鐘 | 點擊砲位，顯示守衛母雞 | 點擊空位能放置一隻母雞 |
| 4 分鐘 | 測試、存檔與記錄問題 | 已測試至少兩個砲位 |

如果老鼠路線仍需要除錯，先完成一條可運作的路線，再把砲位功能縮減成一個砲位。不要用除錯時間追做更多砲位。

## 📚 學習內容

### 1. 加入老鼠角色

1. 開啟角色庫。
2. 搜尋或選擇 `Mouse1`。
3. 將老鼠縮小到適合走在小路上的大小。
4. 把老鼠放到老鼠洞附近。

### 2. 讓老鼠沿著小路移動

在 `Mouse1` 角色中，先使用簡單的滑行積木：

```text
當綠旗被點擊
定位到老鼠洞
滑行 2 秒到第一個轉彎處
滑行 2 秒到第二個轉彎處
滑行 2 秒到飼料桶
```

本週先使用固定座標，不需要學習清單、角度或複雜路徑運算。

### 3. 設計固定砲位

在背景上畫出 3～4 個圓圈或方框，作為母雞可以站立的位置。砲位要放在路旁，不要蓋住老鼠行走的路線。

固定砲位的好處是：

- 學生只需要點擊，不需要拖曳角色
- iPad 和電腦都能操作
- 比較容易判斷能不能放置
- 後面加入金幣時更容易修改

### 4. 點擊砲位放置母雞

先製作一個砲位角色或按鈕角色，加入簡化版程式：

```text
當角色被點擊
如果「這個砲位已使用」等於 0
    顯示守衛母雞
    將「這個砲位已使用」設為 1
否則
    說「這裡已經有守衛了！」 1 秒
```

本週可以先不扣金幣。金幣系統會在後面的課程加入，先把「點擊 → 出現母雞」的流程做成功。

## ✅ 下課前檢查

- [ ] 舞台上有 `Mouse1` 老鼠
- [ ] 老鼠能沿著至少一條路線前進
- [ ] 背景上有固定砲位
- [ ] 點擊空砲位會出現守衛母雞
- [ ] 再次點擊同一砲位不會產生第二隻母雞
- [ ] 專案已經存檔

## ⏭️ 第四週接續內容

下週會讓守衛母雞發射雞蛋。學生將學習建立雞蛋分身、讓雞蛋移動，並偵測雞蛋是否碰到老鼠。

## 🐔 給家長

本週的核心是把「點擊操作」變成遊戲規則：點擊空砲位可以放置母雞，已使用的砲位不能重複放置。這會建立學生對事件和條件判斷的初步理解，金幣和商店會在後續課程再加入。
